# Быстрый старт

[English](../en/getting-started.md) · [Русский](getting-started.md) · [Документация](README.md)

На этой странице пустой Linux-сервер превращается в шлюз с одним MCP-сервером за ним и одним подключённым клиентом.

## Понятия

- **Inbound** — адрес `/mcp/<slug>`, за которым стоит удалённый MCP-сервер со streamable HTTP.
- **Клиент** — токен со сроком действия, набором inbound'ов и лимитами. Один клиент — один человек, приложение или команда.
- **Администратор** входит в панель. Панель и REST API живут по случайному секретному пути.

## Требования

- Linux x86_64 или aarch64 с systemd, root-доступ, `curl`, `tar`, `sha256sum`.
- Домен, указывающий на сервер, если клиенты подключаются из интернета.
- Caddy или nginx перед сервисом для TLS, см. [Установку](install.md#tls). Docker-комплект уже содержит Caddy.

## Установка

```bash
curl -fsSL https://github.com/Echways/ctx-ui/releases/latest/download/install.sh | sudo bash
```

Установщик спросит внешний адрес, который видят клиенты, например `https://mcp.example.com`, и локальный адрес, на котором слушает сервис. Всё остальное — в разделе [Установка](install.md).

## Первый администратор

```bash
sudo ctx-ui admin add admin
```

Команда печатает логин, сгенерированный одноразовый пароль и секретный адрес панели. Откройте его и войдите. Адрес снова покажет `sudo ctx-ui admin path`.

## Первый inbound и клиент

```bash
sudo ctx-ui inbound add learn --url https://learn.microsoft.com/api/mcp
sudo ctx-ui client add "Иванов 4419" --inbound learn --expires 2027-07-01
```

`client add` печатает токен и два адреса подключения. Их же можно скопировать из окна **Подключение** клиента в панели вместе с готовым сообщением для человека.

Изменения из CLI доходят до запущенного сервиса за секунду. Перезапуск не нужен.

## Подключение клиента

| Способ | Адрес |
| ------ | ----- |
| заголовок `Authorization: Bearer <токен>` | `https://<хост>/mcp/<slug>` |
| токен в пути, для клиентов без своих заголовков | `https://<хост>/k/<токен>/mcp/<slug>` |

```bash
claude mcp add --transport http learn https://mcp.example.com/mcp/learn \
    --header "Authorization: Bearer tnk_..."
```

Адрес с токеном равносилен паролю. Не оставляйте его в логах и на скриншотах.

Приложения вроде Claude, ChatGPT и Cursor подключаются по одному адресу сервера и входят в браузере. По умолчанию это выключено, см. [Вход через браузер](oauth.md).

## Лимиты

Лимиты задаются при выпуске клиента или позже:

```bash
sudo ctx-ui client set "Иванов 4419" --rate 60 --quota 500 --reset-days 30
```

См. [Шлюз](gateway.md#лимиты).
