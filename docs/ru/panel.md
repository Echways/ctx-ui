# Панель

[English](../en/panel.md) · [Русский](panel.md) · [Документация](README.md)

Панель управляет inbound'ами, клиентами, ключами API и входом и показывает, что делает шлюз. Всё, что она меняет, применяется в работающем шлюзе сразу.

## Адрес

Панель доступна только по случайному пути из 16 символов. Любой другой путь отвечает 404, поэтому панель нельзя найти сканированием. Адрес покажет `sudo ctx-ui admin path`; `--new` выдаёт новый, он вступает в силу после перезапуска.

## Язык

Панель говорит на языке из `CtxUi__Language`, пока администратор не выбрал свой. Кнопка в верхней панели и ссылка под формой входа переключают английский и русский. Выбор хранится в cookie год. См. [Настройки](configuration.md#язык).

## Разделы

| Раздел | Содержимое |
| ------ | ---------- |
| Обзор | Активные клиенты, вызовы и сбои upstream за сутки; итоги по inbound'ам и по дням. |
| Метрики | Сутки, 7, 30 или 90 дней: вызовы, ошибки, время ответа p50, p95 и p99, трафик, путь клиентов от первого вызова до ответа инструмента, разбивка по inbound'ам, инструментам, методам, клиентам и устройствам, частые ошибки с HTTP-кодом, отказы шлюза по причинам. Любая строка сужает отчёт до этого клиента, inbound'а или инструмента. |
| Inbounds | Создание, правка, включение и выключение, удаление. |
| Клиенты | Создание, правка, включение и выключение, поиск, окно **Подключение**, новый токен, сброс квоты, устройства. |
| Журнал | Последние вызовы с HTTP-кодом, фильтр по клиенту. |
| Ключи API | Выпуск, отзыв, ссылка на Swagger UI. |
| OAuth | Переключатель входа через браузер, провайдеры, значения по умолчанию для устройств. См. [Вход через браузер](oauth.md). |

Окно **Подключение** клиента показывает токен, адреса и готовое сообщение для человека.

Периоды метрик ограничены сроком хранения журнала: для 90 дней нужен `CtxUi__UsageRetentionDays` не меньше `90`.

## Настройки inbound'а

Таймаут запроса inbound'а (по умолчанию 300 секунд, от 1 до 3600) и предел тела запроса (по умолчанию 4 МБ, от 1 КБ до 64 МБ) задаются только в панели.

## Вход

Пароль администратора генерируется, длиной 20 символов, показывается один раз и хранится хешем. Пять неверных попыток закрывают логин на 15 минут. Cookie сеанса живёт 7 дней со скользящим продлением.

```bash
sudo ctx-ui admin password admin
sudo ctx-ui admin list
```

`admin password` выдаёт новый пароль, закрывает сеансы и снимает блокировку. `admin list` показывает блокировки.
