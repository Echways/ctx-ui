# CLI

[English](../en/cli.md) · [Русский](cli.md) · [Документация](README.md)

Команды запускаются через `sudo`: обёртка сама загружает настройки и переключается на пользователя сервиса. В Docker перед командой ставится `docker compose exec ctx-ui`.

Изменения из CLI доходят до запущенного сервиса за `RefreshInterval` (1 секунда). Перезапуск не нужен.

| Группа | Назначение |
| ------ | ---------- |
| [`admin`](#admin) | Администраторы панели |
| [`inbound`](#inbound) | Адреса, за которыми стоят MCP-серверы |
| [`client`](#client) | Токены, лимиты, устройства, привязанные аккаунты |
| [`usage`](#usage) | Итоги по дням и журнал вызовов |
| [`oauth`](#oauth) | Вход через браузер и его провайдеры |
| [`apikey`](#apikey) | Ключи REST API |
| [`backup`](#backup) | Согласованная копия данных |
| [`extension`](#extension) | Расширения панели |
| [Сервис](#сервис) | `up`, `down`, `update`, `uninstall`, `version` |

## admin

| Команда | Действие |
| ------- | -------- |
| `admin add <логин>` | Создать администратора; печатает пароль и адрес панели. |
| `admin password <логин>` | Новый пароль; закрывает сеансы, снимает блокировку. |
| `admin list` | Список с состоянием блокировки. |
| `admin remove <логин>` | Удалить. |
| `admin path [--new]` | Адрес панели; `--new` выдаёт новый, действует после перезапуска. |

Логин: от 1 до 64 символов, `A-Z a-z 0-9 . _ -`.

## inbound

| Команда | Действие |
| ------- | -------- |
| `inbound add <slug> --url <адрес>` | Inbound на MCP-сервер со streamable HTTP. |
| `inbound list` | Slug, состояние, адрес. |
| `inbound enable\|disable <slug>` | Включить или выключить без удаления. |
| `inbound remove <slug>` | Удалить и отозвать у всех клиентов. |

Параметры `add`:

| Параметр | Значение |
| -------- | -------- |
| `--name <текст>` | Название в списке; по умолчанию slug. |
| `--header Имя=значение` | Заголовок для upstream, повторяемый, хранится зашифрованным. |
| `--forward-identity` | Передавать upstream заголовки личности клиента, см. [Шлюз](gateway.md#что-получает-upstream). |

Slug: от 1 до 64 символов, `a-z 0-9 -`, без дефиса по краям.

## client

| Команда | Действие |
| ------- | -------- |
| `client add <имя> --inbound <slug>` | Выпустить клиента; печатает токен и адреса. |
| `client show <имя>` | Токен, адреса, лимиты, расход квоты. |
| `client set <имя>` | Изменить срок, inbound'ы, лимиты. |
| `client reset <имя>` | Обнулить счётчик квоты и начать период заново. |
| `client reissue <имя>` | Новый токен; старый перестаёт работать. |
| `client list` | Имя, состояние, срок, последнее обращение, квота, inbound'ы. |
| `client devices <имя>` | Устройства: приложения, способ входа, последнее использование, IP, состояние. |
| `client device-off <имя> <id>\|--all` | Отключить устройство (id или его начало) или все. |
| `client invite <имя>` | Одноразовая ссылка для привязки чужого аккаунта; действует 7 дней. |
| `client links <имя>` | Аккаунты, привязанные к клиенту. |
| `client unlink <имя> <провайдер>` | Снять привязки провайдера. |
| `client enable\|disable <имя>` | Включить или выключить без удаления. |
| `client remove <имя>` | Удалить. |

Параметры `add` и `set`:

| Параметр | Значение |
| -------- | -------- |
| `--inbound <slug>` | Повторяемый; в `set` заменяет весь набор. |
| `--expires ГГГГ-ММ-ДД` | Доступ закрывается в 00:00 UTC этого дня; `never` в `set` снимает срок. |
| `--meta ключ=значение` | Только `add`; повторяемый; уходит upstream как `X-Mcp-Meta-<ключ>`. |
| `--rate N` | Запросов в минуту. |
| `--concurrency N` | Одновременных `POST`. |
| `--quota N` | `tools/call` за период. |
| `--reset-days N` | Длина периода квоты; без него квота разовая. |
| `--devices N` | Лимит устройств при входе через браузер; `none` в `set` снимает его. |
| `--direct-key on\|off` | Работает ли ключ в заголовке и адресе или только для входа. |

В `set` значение `none` снимает лимит, не указанные параметры не меняются. Лимиты описаны в разделе [Шлюз](gateway.md#лимиты).

Имя: от 1 до 100 символов, уникально без учёта регистра, без управляющих символов. Имя с пробелами берётся в кавычки.

```bash
sudo ctx-ui client set "Иванов 4419" --quota 500 --reset-days 30 --rate 60
sudo ctx-ui client set "Иванов 4419" --rate none
```

## usage

| Команда | Действие |
| ------- | -------- |
| `usage days [--days N]` | Итоги по дням за N последних дней (по умолчанию 7, максимум 3650). |
| `usage log [--limit N]` | Последние вызовы, новые сверху (по умолчанию 50, максимум 1000). |

Обе принимают `--client <имя>`. Время в UTC. Данные попадают в базу раз в `FlushInterval` (5 секунд), поэтому видны с небольшой задержкой.

## oauth

| Команда | Действие |
| ------- | -------- |
| `oauth status` | Состояние, адрес метаданных сервера, значения по умолчанию, провайдеры и их адреса возврата; предупреждает, если OAuth невозможен из-за публичного адреса. |
| `oauth on\|off` | Включить или выключить вход через браузер; `off` предупреждает о клиентах без постоянного ключа. |
| `oauth key on\|off` | Разрешить или запретить вход по ключу. |
| `oauth set [--idle-days N] [--self-revoke on\|off] [--devices N\|none] [--direct-key on\|off]` | Срок неактивности устройств, самостоятельное отключение, значения по умолчанию для новых клиентов. |
| `oauth provider set <имя> --client-id <id>` | Добавить провайдера или изменить его. |
| `oauth provider on\|off\|remove <имя>` | Включить, выключить, удалить. |
| `oauth provider list` | Настроенные провайдеры. |

`provider set` берёт секрет из `--client-secret`, со стандартного ввода при `--client-secret-stdin` или из `CTX_UI_PROVIDER_SECRET`. Для `oidc` добавьте `--issuer <https://…>` и `--title <текст>`. Имена: `google`, `microsoft`, `github`, `gitlab`, `yandex`, `vkid`, `discord`, `telegram`, `oidc`. См. [Вход через браузер](oauth.md).

## apikey

| Команда | Действие |
| ------- | -------- |
| `apikey add <название>` | Выпустить ключ REST API; печатает его один раз вместе с адресами API и Swagger. |
| `apikey list` | Название, начало ключа, дата выпуска. |
| `apikey remove <название>` | Отозвать; запросы с ключом сразу получают 401. |

Название: от 1 до 64 символов, `A-Z a-z 0-9 . _ -`. См. [REST API](api.md).

## backup

`backup <каталог>` записывает согласованную копию базы и каталога `keys/` без остановки сервиса. Каталог должен отсутствовать или быть пустым. См. [Установку](install.md#резервная-копия).

## extension

| Команда | Действие |
| ------- | -------- |
| `extension install <архив>` | Установить или заменить расширение; архив проверяется по правилам сервера. |
| `extension list` | Установленные расширения и их состояние: `ok`, `disabled`, `incompatible`, `invalid`. |
| `extension remove <id> [--purge]` | Удалить расширение; `--purge` удаляет и его данные. |

После каждого изменения перезапустите сервис. См. [Расширения панели](extensions.md#установка-обновление-удаление).

## Сервис

| Команда | Действие |
| ------- | -------- |
| `up` | Запустить сервис и снова включить запуск при загрузке. |
| `down` | Остановить сервис и не запускать его после перезагрузки. |
| `update [версия]` | Обновить до последнего релиза или до указанной версии. |
| `uninstall [--keep-data] [--yes]` | Удалить программу; без `--keep-data` также настройки, данные и пользователя. |
| `version` | Установленная версия. |

Эти команды есть при установке через systemd. См. [Установку](install.md).
