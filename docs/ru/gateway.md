# Шлюз

[English](../en/gateway.md) · [Русский](gateway.md) · [Документация](README.md)

Шлюз отвечает на MCP-запросы по адресу `/mcp/<slug>`, проверяет клиента, применяет его лимиты и передаёт запрос upstream-серверу.

## Аутентификация

| Способ | Адрес |
| ------ | ----- |
| заголовок `Authorization: Bearer <токен>` | `https://<хост>/mcp/<slug>` |
| токен в пути, для клиентов без своих заголовков | `https://<хост>/k/<токен>/mcp/<slug>` |

Адрес с токеном равносилен паролю. Поэтому в инструкции по установке журнал доступа nginx выключен. См. [Установку](install.md#tls).

Приложения могут подключаться и по одному адресу, входя в браузере. См. [Вход через браузер](oauth.md).

## Лимиты

Каждый лимит необязателен. Не заданный лимит не действует.

| Лимит | Что считает | При превышении |
| ----- | ----------- | -------------- |
| `--rate` | Все запросы, token bucket. | HTTP 429, `Retry-After: <секунд до следующего>`. |
| `--concurrency` | Одновременные `POST`. | HTTP 429, если слот не освободился за 1 секунду, `Retry-After: 1`. |
| `--quota` | `tools/call` за период. | HTTP 200, результат tool с `isError: true` и временем сброса. |

Квоту расходует только `tools/call`. С исчерпанной квотой клиент по-прежнему подключается и видит список tools. Отказ приходит результатом tool, и модель пересказывает его человеку. Вызовы, на которые upstream ответил HTTP 400 и выше или не ответил, возвращаются в квоту.

Без `--reset-days` квота разовая. Лимиты задаются в `client add` и `client set`, см. [CLI](cli.md#client).

Ожидание слота для `--concurrency` задаёт `CtxUi__ConcurrencyWait`, см. [Настройки](configuration.md#переменные).

## Лимиты inbound'а

Таймаут запроса (по умолчанию 300 секунд) и предел тела запроса (по умолчанию 4 МБ) принадлежат inbound'у и задаются в панели. Тело больше предела получает 413.

## Ответы

| Статус | `error` | Причина |
| ------ | ------- | ------- |
| 401 | `token_missing` | Нет токена. |
| 401 | `token_unknown` | Токен не найден. |
| 401 | `client_disabled` | Клиент отключён. |
| 401 | `client_expired` | Срок истёк. |
| 404 | `inbound_not_found` | Inbound'а нет, он выключен или не выдан клиенту. |
| 429 | `rate_limited`, `too_many_concurrent` | Превышен лимит. |
| 413 | `body_too_large` | Тело больше предела inbound'а. |
| 400 | JSON-RPC `-32600` | Тело не JSON-RPC или пакет больше 100 сообщений. |

Язык этих сообщений задаёт `CtxUi__Language`.

## Что получает upstream

Запрос клиента без токена плюс заголовки inbound'а.

С `--forward-identity` шлюз добавляет `X-Mcp-Client-Id`, `X-Mcp-Client-Name` и `X-Mcp-Meta-<ключ>` для каждого `--meta` клиента. Значения — UTF-8 с процентным кодированием. Такие же заголовки от клиента вырезаются.

Заголовки inbound'а хранятся зашифрованными.

## Проверка здоровья

`GET /healthz` отвечает 200, когда сервис и его база здоровы. Его использует проверка здоровья Docker-образа.
