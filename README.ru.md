## Зачем ctx-ui

MCP-сервер обычно — один адрес и один общий секрет. ctx-ui ставит между этим сервером и людьми прослойку, чтобы доступ можно было выдавать, ограничивать и отзывать для каждого клиента отдельно.

- **Один адрес на сервер.** Inbound — это `/mcp/<slug>`, за которым стоит удалённый MCP-сервер со streamable HTTP. Адрес upstream и его секретные заголовки не доходят до клиента.
- **Токен на клиента.** У каждого клиента свой токен, срок действия и набор inbound'ов. Перевыпустить или отключить его можно, не трогая остальных.
- **Лимиты, которые ведут себя прилично.** Частота запросов, одновременные запросы и квота вызовов инструментов за период. Исчерпанная квота приходит результатом инструмента, и модель объясняет её человеку, а соединение не рвётся.
- **Вход в браузере.** Claude, ChatGPT и Cursor подключаются по одному адресу сервера. Войти можно ключом клиента, через Google, GitHub или любого провайдера OpenID Connect. По умолчанию выключено.
- **Панель, которая показывает происходящее.** Обзор, метрики с перцентилями времени ответа, журнал вызовов, устройства, ключи API. Живёт по случайному секретному пути.
- **Всё автоматизируется.** CLI и REST API со Swagger UI покрывают всю панель. Изменения доходят до работающего шлюза за секунду.
- **Расширяется.** Расширения панели добавляют разделы, блоки и действия из zip-архива, без пересборки ctx-ui.
- **Серверы, не выходя из панели.** Необязательный конструктор собирает FastMCP-серверы из форм или кода, запускает каждый в изолированном Docker-контейнере и подключает как inbound.
- **Просто запускать.** Один бинарник с systemd или Docker с Caddy на Linux x86_64 и aarch64. Английский и русский везде.

## Установка

Бинарник и systemd:

```bash
curl -fsSL https://github.com/Echways/ctx-ui/releases/latest/download/install.sh | sudo bash
```

Нужен Linux x86_64 или aarch64 с systemd. Сервис говорит по обычному HTTP: для TLS поставьте перед ним Caddy или nginx. Docker с Caddy, обновление, удаление и резервная копия описаны в разделе [Установка](docs/ru/install.md).

## Быстрый старт

```bash
sudo ctx-ui admin add admin
sudo ctx-ui inbound add learn --url https://learn.microsoft.com/api/mcp
sudo ctx-ui client add "Иванов 4419" --inbound learn --expires 2027-07-01
```

`admin add` печатает логин, одноразовый пароль и секретный адрес панели. `client add` печатает токен и адреса подключения. В Docker перед командами ставится `docker compose exec ctx-ui`.

Подключите клиента с токеном в заголовке:

```bash
claude mcp add --transport http learn https://mcp.example.com/mcp/learn \
    --header "Authorization: Bearer tnk_..."
```

Подробнее — в разделе [Быстрый старт](docs/ru/getting-started.md).

## Что входит

| Область                     | Возможности                                                                                                                                                                    |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Шлюз                           | Inbound'ы со streamable HTTP, токены клиентов, срок действия, аутентификация заголовком и путём.                               |
| Лимиты                       | Частота, одновременные запросы, квота `tools/call` с периодом сброса, таймаут запроса и размер тела.            |
| Вход через браузер | OAuth для MCP-приложений, девять способов входа, ссылки-приглашения, устройства с лимитом.                             |
| Панель                       | Обзор, метрики, журнал вызовов, клиенты, inbound'ы, ключи API, английский и русский.                                              |
| CLI                                | `admin`, `inbound`, `client`, `usage`, `oauth`, `apikey`, `backup`, `extension`.                                                                                          |
| REST API                           | Вся панель под `/api/v1`, документ OpenAPI 3.1, Swagger UI.                                                                                                         |
| Расширения               | Разделы, слоты, действия, эндпоинты, фоновые сервисы и база данных, шаблон проекта и браузерные тесты. |
| Конструктор             | FastMCP-серверы из форм, импорта OpenAPI или кода; изолированные контейнеры; версии и откат.                                |
| Эксплуатация           | Установка, обновление и удаление одной командой, согласованная копия работающего сервиса.                    |
